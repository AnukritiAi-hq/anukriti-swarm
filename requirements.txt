# Deterministic pharmacogenomics core.
# 13-gene CPIC-pinned phenotype engine + VCF callers + provenance manifest.
# rules/phenotype_rules.py is a thin re-export over this package.
# Published to PyPI from https://github.com/AnukritiAi-hq/anukriti-pgx-core
#
# Pin the patch version exactly — the library is the biomedical truth
# layer and new versions may contain CPIC table updates that require
# regression review in Swarm before adoption. Bump this pin deliberately.
#
# 0.11.0 — NOT CLINICALLY APPROVED. See anukriti-pgx-core
# docs/REGRESSION_REVIEW_0.10.0_to_0.11.0.md, whose own verdict is
# "NOT APPROVED by this document": the reviewer is the engine
# maintainer, a programmer, not a clinician. No clinician has signed off
# on any of the three changes below. Read that document before relying
# on this pin for anything patient-facing.
#
# 1. DPYD HapB3 `tag_without_causal` — when the causal rs75017182 is
#    genotyped and REFERENCE while the tag rs56038477 (c.1236G>A) is
#    present, the decreased-function call is WITHDRAWN:
#      0.10.0  *1/c.1236G>A  Intermediate Metabolizer  REDUCE_50PCT
#      0.11.0  *1/*1         Normal Metabolizer        STANDARD
#    THIS IS THE LESS CONSERVATIVE DIRECTION. A dose reduction is
#    removed; a patient who would have started on 50% of the standard
#    fluoropyrimidine dose now starts on the full dose. The grounds are
#    that CPIC publishes no stand-alone c.1236G>A allele (PharmCAT
#    resolves the conflict the same way; Turner 2024, PMID 38129972),
#    not a cohort measurement — no benchmark in that repo exercises it,
#    and the genotype has never been observed in a South Asian cohort.
#    `tag_only` (causal never genotyped) and a `./.` no-call still
#    reduce. `hapb3_basis` still reports "tag_without_causal", so the
#    finding is withdrawn from the call, not the report — but Swarm
#    consumes Layer 2 (PhenotypeEngine) only and never sees that field,
#    so Swarm cannot render the withdrawal. See PR for details.
# 2. Diplotype truncation (>2 variant-allele copies) now keeps the two
#    alleles most impaired by CPIC function instead of the two sorting
#    first by allele name. More conservative. Layer 1 (GeneCaller)
#    only — Swarm does not call it.
# 3. DPYD panel widens from 18 to 33 alleles; 15 CPIC actionable alleles
#    that were previously answered *1/*1 Normal Metabolizer become
#    callable. More conservative. This is the one change Swarm does see:
#    the pinned DPYD diplotype table grows 190 -> 595 entries, so
#    infer_phenotype() now resolves diplotypes it previously could not.
#
# Skips 0.10.0, whose bump (PR #2, deps/pgx-core-0.10.0) is still open
# and unmerged; 0.11.0 contains it.
anukriti-pgx-core==0.11.0
