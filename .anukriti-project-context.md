## What this project is

**Anukriti Swarm** is a distributed multi-agent genomic intelligence system for population-aware pharmacogenomic reasoning. Core mission:

> **"Population-aware pharmacogenomic risk analysis before clinical trials."**

The platform decomposes pharmacogenomic reasoning into specialized, verifiable agent tasks: population context → pharmacogene reasoning → evidence retrieval → graph reasoning → sufficiency governance → deterministic verification → explainable risk synthesis. **Population is a first-class reasoning dimension**, not metadata.

Strategic positioning (set in session #14): **evidence-governed drug-safety infrastructure**, not a healthcare-AI model. The platform is the equity-aware reasoning substrate the rest of the Anukriti platform consumes.

Scope firewall — the platform is NOT:
- a generic RAG chatbot
- a generic healthcare assistant
- an EHR system or clinical copilot
- a document search engine
- a GraphRAG framework
- an LLM-as-judge system
- a SaaS dashboard or multi-tenant API
- an authentication / authorization service

Every layer enforces this boundary through closed enums at the type boundary. Drift into generic territory requires a deliberate code change, never a runtime configuration.

Added EUR + Latino/Hispanic/Admixed-American keywords. **AFR deliberately excluded** to keep the AFR-codeine refusal demo (which tests the safety contract) honest.

## Evidence Sufficiency Layer — 4 deterministic rule tables

**SufficiencyDecisionEngine — 12 base rules + 1 opt-in M4 → 8 decisions**
```
R1  hard conflict or CONFLICT_FREE MISSING       -> BLOCK
R2  PHENOTYPE MISSING                             -> BLOCK
R3  RECOMMENDATION MISSING                        -> BLOCK
R4  provenance incomplete                         -> ABSTAIN
R5  POPULATION MISSING                            -> ESCALATE
R6  CPIC MISSING                                  -> REQUEST_MORE
R7  ALLELE MISSING                                -> REQUEST_MORE
R8  RECOMMENDATION UNCERTAIN                      -> DOWNGRADE          (priority: > M4)
M4  POPULATION UNCERTAIN + 4 facets COVERED       -> EXTRAPOLATION_*    (opt-in only)
R9  POPULATION UNCERTAIN                          -> DOWNGRADE          (yields to M4 when on)
R10 any other UNCERTAIN                           -> DOWNGRADE
R11 CONFLICT_FREE UNCERTAIN (soft only)           -> PASS_WITH_CAVEAT
R12 all clean                                     -> SUFFICIENT
```

**SetLevelEvidenceVerifier (SURE-RAG style) — 10 rules → 5 verdicts**
```
V1  named AVOID/USE invertor -> REFUTED
V2  other hard conflict      -> CONFLICTING
V3  PHENOTYPE missing        -> INSUFFICIENT
V4  RECOMMENDATION missing   -> INSUFFICIENT
V5  other missing facet      -> INSUFFICIENT
V6  empty KG path bundle     -> UNCERTAIN
V7  POPULATION uncertain     -> UNCERTAIN
V8  other uncertain facet    -> UNCERTAIN
V9  CONFLICT_FREE uncertain  -> UNCERTAIN
V10 all clean                -> SUPPORTED
```

**UncertaintyScoringEngine — 9 rules → 4 tiers**
```
U1 hard conflict                 -> UNSAFE
U2 missing non-conflict facet    -> HIGH
U3 POPULATION uncertain          -> HIGH
U4 empty KG path bundle          -> HIGH
U5 >=2 uncertain facets          -> HIGH
U6 CONFLICT_FREE uncertain       -> MODERATE
U7 exactly 1 non-core uncertain  -> MODERATE
U8 KG path bundle with 1 path    -> MODERATE
U9 otherwise                     -> LOW
```
Tier → action: `UNSAFE→BLOCK`, `HIGH→REQUEST_MORE`, `MODERATE/LOW→PROCEED`.

**PopulationEvidenceBiasDetector — 3 closed bias kinds**
```
EUROCENTRIC_IMBALANCE      target non-EUR + target evidence=0 + EUR evidence>0
ANCESTRY_SCARCITY          target allele count / max < 0.5 (default)
```

## Key design invariants (still hold)

1. **No clinical decisions.** Outputs are research artifacts, not clinical advice. Enforced in code (closed enums, scope firewall, `GenerativeBoundary`).
2. **Deterministic first.** Rule tables always run before any LLM call. Closed-enum contracts make drift a review-time catch.
3. **Population is reasoning context, not metadata.** `SuperPopulation` is a first-class closed enum; allele frequencies are KG edges with explicit weights; bias detection has concrete numeric thresholds.
4. **Every claim has provenance.** The MCP `MCPProvenanceStore` walks `narrative → recommendation → phenotype → CPIC rule → evidence` in one call. Every KG edge requires non-empty `ProvenanceStamp.source_id`.
5. **Off-by-default for new capabilities.** Constructor args, not feature flags.
6. **Every refusal is named.** Abstentions and blocks cite a specific rule ID (R1..R12, M4, V1..V10, U1..U9, or named bias kind).
7. **GenerativeBoundary forbids 4 actions:** `infer_phenotype`, `override_recommendation`, `bypass_verification`, `fabricate_claim`.
8. **Demo signature preservation:** the 7 byte-locked flagship demos must produce byte-identical output session-over-session. Diff = red flag.
