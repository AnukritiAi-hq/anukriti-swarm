# Anukriti PGx — Demo Video (Remotion)

A 3-minute demo video built with [Remotion](https://www.remotion.dev/) for the Agents Assemble 2026 submission.

## Scene timeline (3:00 @ 30fps = 5400 frames)

| Time | Scene | Duration | Content |
|------|-------|----------|---------|
| 0:00–0:30 | Intro | 30s | Problem statement: 14% of South Asians can't activate clopidogrel |
| 0:30–1:30 | Consultant | 60s | `clips/consultant.mp4` — PGx Consultant demo |
| 1:30–2:15 | Evidence | 45s | `clips/evidence.mp4` — Evidence Reviewer demo |
| 2:15–2:45 | Prescriber | 30s | `clips/prescriber.mp4` — Prescriber Agent demo |
| 2:45–3:00 | Outro | 15s | Brand pillars + CTA |

## Setup

### 1. Install dependencies

```bash
cd hackathon/video
npm install
```

### 2. Drop in your clips

Place your screen recordings in `public/clips/`:
- `public/clips/consultant.mp4` — PGx Consultant agent demo
- `public/clips/evidence.mp4` — Evidence Reviewer demo
- `public/clips/prescriber.mp4` — Prescriber Agent demo

**Tips:**
- Resolution: 1920×1080 or 16:9 ratio
- Record with the clip audio **muted or will be muted** — the voiceover takes over
- Length doesn't need to match the scene duration exactly — the video will loop/pause at the end of the clip

### 3. Add background music

Drop a royalty-free background track at:
```
public/audio/background.mp3
```

Recommended sources:
- [YouTube Audio Library](https://www.youtube.com/audiolibrary) (filter: ambient/cinematic)
- [Free Music Archive](https://freemusicarchive.org/)
- [Pixabay Music](https://pixabay.com/music/) (safe for hackathon use)

Look for "corporate", "tech", or "ambient" in the 3-minute range.

### 4. Generate the voiceover (ElevenLabs)

```bash
export ELEVENLABS_API_KEY=sk_your_rotated_key_here
node scripts/generate-voiceover.mjs
```

This creates `public/audio/voiceover.mp3` using the Rachel voice (female, professional).

To use a different voice, set `ELEVENLABS_VOICE_ID`:
```bash
export ELEVENLABS_VOICE_ID=TxGEqnHWrfWFTfGW9XjX  # Josh (male)
node scripts/generate-voiceover.mjs
```

### 5. Preview in Remotion Studio

```bash
npm start
```

Opens browser at http://localhost:3000 — scrub through the timeline, make adjustments.

### 6. Render the final video

```bash
npm run build
```

Output: `out/demo.mp4` (H.264 MP4, ready for upload)

## Customizing

**Edit the voiceover script:** `scripts/generate-voiceover.mjs` — change the `SCRIPT` constant.

**Edit scene timings:** `src/DemoVideo.tsx` — adjust the frame offsets for each `Sequence`.

**Edit scene visuals:** `src/scenes/IntroScene.tsx`, `ClipScene.tsx`, `OutroScene.tsx`.

## Troubleshooting

**"Cannot find module 'remotion'"** — run `npm install` first.

**Voiceover too long/short** — ElevenLabs output duration varies. Preview in Studio; if the VO runs past the 3-minute mark, trim the `SCRIPT` in the generation script and regenerate.

**Clips look stretched** — the `ClipScene` uses `objectFit: "contain"` to preserve aspect ratio. Re-export your clips as 16:9 if they look letterboxed.

**Audio out of sync** — the voiceover is one continuous track synced to 0:00. If you re-record the VO, it should naturally align with scene timings as long as you kept the script paragraph structure.
